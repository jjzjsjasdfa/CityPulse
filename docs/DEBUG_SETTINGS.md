# 调试设置与未读提醒

底栏“我的”整合收藏，右上角齿轮进入设置，可以切换调试模式，不需要重新打包。偏好保存在本机；演示构建初次默认开启，普通构建初次默认关闭，以后以保存的选择为准。

- 开启：长沙五一广场虚拟定位，独立的 200 条活动测试 API，以及独立的收藏、指引和未读存储。
- 关闭：浏览器 / 原生前台真实定位与正式 API。接口暂未就绪时显示空地图和连接状态，绝不使用虚构数据填充。
- 自选时间输入北京时间 `YYYY-MM-DD HH:mm`，应用后正常流逝。地图时间大小、过期过滤、附近新活动查询使用同一时钟。动画速度仍使用真实时间。
- “使用数据起始时间”可以回到当前测试数据附近的时间；“应用并重播新活动”清除测试已读记录，并在选择的时间重新发布周围 8 个方向的 16 条已有活动，不增加总条数。过期的重播活动会调整为该时刻开始、持续 6 小时。
- 应用设置重建本次地图会话，以便验证启动效果。普通地图 / 发现 / 我的 / 设置切页仍保留视野。
- 默认新活动提示半径为 7 公里，调试滑条为 0–30 公里，同时限制边缘导引和活动光圈；0 关闭两者。距离始终以用户定位为中心，与地图拖动无关。范围外活动正常显示、不启动光圈计时，离开范围时取消未完成计时而不标记完成。正式模式使用 7 公里。调整半径会重置查询游标，保留已读版本；需要重新测试已看过的活动时使用重播。
- 重叠活动切换间隔默认 1 秒，调试可设 0.5–5 秒。仅全名层级对屏幕距离不超过 12 像素且实际距离不超过 30 米的活动原位轮播，按住地图时暂停。全部图标保留各自真实位置，不因文字碰撞而远移；其他层级保留全部圆点自然堆叠，文字使用原来的避让规则。
- 五一广场 12 条和市中心共享空间 8 条活动使用两组相同经纬度，其中既有同时发生，也有不同时间发生的活动。保持总计 200 条和原有区域、时间分布。
- 地图延伸到全屏，底栏悬浮并通过 safe-area-context 避开系统手势区域。顶部多选类别随层级浮现、可横向滚动，隐藏类别也隐藏对应导引。触屏设备不显示放大缩小按钮。
- 调试时间改变会重置调试指引和未读记录，防止向过去查询时复用未来的增量时间戳；正式记录不受影响。

调试 API 自动使用 Expo 开发电脑的主机地址，网页使用当前网页的主机地址，端口为 18082。没有开发主机信息的离线包才回退 localhost（Android 为 10.0.2.2）。`EXPO_PUBLIC_DEMO_API_URL` 可以覆盖自动地址。正式 API 使用 `EXPO_PUBLIC_API_URL`，缺省端口为 8000。

手机 Expo Go 测试：电脑与手机连接同一 Wi-Fi，在 backend 运行 `python scripts/run_demo.py`，在 mobile 运行 `npm run start:demo -- --lan` 并扫码。测试启动脚本监听局域网，保持两个终端运行。手机浏览器打开 `http://开发电脑的局域网IP:18082/api/v1/events?page_size=1` 应返回 JSON；若打不开，检查 Wi-Fi 是否隔离设备以及 Windows 防火墙的 Python 专用网络权限。Expo 的 tunnel 只代理打包服务，不会代理独立测试 API；远程测试需另行配置手机可访问的 `EXPO_PUBLIC_DEMO_API_URL` 并重启 Expo。
只有独立的 `app.demo` 接受 `demo_now` 参数。正式 `app.main` 不挂载模拟发布入口；客户端在正式模式不发送调试时间。
接口返回仍保持现有活动契约，未来数据库接入使用正式 API 配置即可。

## 提醒生命周期

启动后第一次取得附近新活动时，全部相关类别沿四边快速流动，保持亮起约 0.5 秒，随后用 1 秒淡化成常规八方向指引。切换页面不会再次播放；重新启动或调试重播可以播放。减少动态效果的系统偏好会关闭快速流动与闪烁，保留颜色和淡入淡出。

指引使用独立的高明度类别色，宽约 17–21 像素，向内渐隐到透明。固定 32 段围成连续边框，相邻段共享颜色端点；四边遮罩叠合处理角落，避免间断或角部缩小。颜色先计算后混合，不再堆叠许多椭圆。

活动进入内部可见区域并停留 350 毫秒后，方向指引退场。提示半径内的新活动第一次实际显示在地图上时开始 60 秒光圈；范围外和尚未轮播到的活动不会提前计时。光圈与图标共用锚点，中心向外扩散，每 2.4 秒一轮，内部不透明、边缘柔化。网页使用 CSS 合成动画，iOS Apple Maps 使用原生驱动动画；Android 自定义标记需要在光圈存续期间更新位图，结束后恢复缓存，密集场景仍需真机性能验证。

计时结束或打开详情，任一条件满足即结束该发布版本的新活动提示并持久保存；未完成前退出应用，再次启动重新计时。名称只保留加粗类别颜色文字。新活动标记保留黑色轮廓，提示完成后恢复白色。首次迁移兼容原来的详情已读记录。地图 API 新增可选 published_at，用于区分同一活动的重新发布。

验证：`npm run smoke:overlap` 覆盖悬浮地图、触屏控件、默认半径、轮播、类别和时间设置；`npm run smoke:alerts` 覆盖一分钟生命周期、重启和点击取消；`smoke:hits` 回归精确点击。

## iPhone 高刷新率

独立应用的 Info.plist 已启用 CADisableMinimumFrameDurationOnPhone。Expo Go 自身的 Info.plist 无法通过项目热更新修改，需要独立 development / release build 验证 ProMotion。系统仍会按设备、低电量模式、温度和内容选择刷新率，无法保证固定 120 Hz。原生地图手势保持在 SDK 内，JS 碰撞布局最多每 100 ms 重算，避免每个显示帧重建整批标记；只有布局位移执行短过渡。监测面板的 JS FPS 不是 MapKit 实际显示帧率。

## 流畅度监测

调试模式下默认开启，可单独关闭。地图上显示每秒 FPS、P95 帧间隔、超过 34 ms 的慢帧数、最长帧。持续 3 个采样窗口低于 45 FPS 或 P95 超过 34 ms，会显示“持续不流畅 · 需要优化”。后台暂停采样；切换到我的或设置仍记录，但隐藏覆盖面板。

记录最多保留 180 个窗口，每 10 秒及结束时保存到本机 `@citypulse/debug-performance-v1`。采样回调只存时间差，统计、排序和界面更新每秒执行一次；正式模式不采集。网页同时统计超过 50 ms 的主线程长任务。原生端数值为 **JS 帧率**，不代表地图 SDK / GPU 的实际 UI 帧率，仍需真机检查。

`npm run smoke:performance` 测量基础样本，并使用明确标记的人工阻塞验证警报；生成 `mobile/artifacts/performance-report.json`。人工阻塞不算应用自身性能问题。
