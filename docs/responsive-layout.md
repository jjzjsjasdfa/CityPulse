# 响应式布局

按窗口逻辑宽度适配，手机浏览器与原生应用遵循同样的断点：

| 宽度 | 导航 | 活动详情 |
| --- | --- | --- |
| 小于 768 | 底部悬浮导航 | 模态详情 |
| 768–1199 | 左下角横向圆角悬浮栏，最大宽度 360 | 320 宽右侧详情栏 |
| 1200 及以上 | 左上角纵向圆角悬浮栏，宽度上限 80，文字位于图标下方 | 400 宽右侧详情栏 |

桌面地图铺满导航下方，不保留整条空白侧栏；地图类别筛选避让左上角导航。其他页面留出 104 的导航空间。平板与手机页面底部留出导航空间。

所有布局支持导航栏内滑动切页：横向栏左右滑，纵向栏上下滑，鼠标按住拖动同样可用。超过 8 的轴向位移才接管手势，拖动预览目标，松手确认；取消手势不切页，并抑制拖动结束后的误点击。手势仅绑定导航栏，不绑定地图或整个页面。

选中背景为独立的 Animated 图层，拖动时连续跟随位移，释放或点击后以无过冲弹簧贴合目标；页面内容淡入 160ms。动画仅改变 transform/opacity，不重建地图。系统减少动态效果开启时取消弹簧和淡入。横竖导航统一外圆角 32、内圆角 25，保留 6 的内边距。

布局规则集中在 `mobile/src/layout.ts`。主界面只调整现有内容的边距，不因布局变化重建地图组件；Leaflet 的 ResizeObserver 会更新地图尺寸。活动详情保持同一组件状态，切换展示容器时保留当前活动与纠错输入。

发现页与收藏卡片按实际内容宽度排列：不足 700 单列，700–1099 双列，1100 及以上三列。收藏列表维持单列。设置表单最大宽度 840，居中显示。列数变化会重新排版列表；筛选、搜索与收藏数据由父级状态保留。

Web 地图沿用输入能力检测：触屏隐藏缩放按钮，鼠标设备保留按钮；平台判断不作为布局断点。导航中的地图入口统一命名为“探索”。

验证：前端启动后，在 mobile 目录运行 `node scripts/smoke-responsive.mjs`。测试拦截 API 使用虚构数据，验证三种宽度、活动详情持续打开、地图在切换宽度与关闭详情时不卸载。截图位于忽略的 artifacts 目录；底图瓦片取决于外部网络，不作为该测试的通过条件。
