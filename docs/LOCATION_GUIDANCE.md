# 定位与附近新活动方向提示

## 启动与定位

- 默认进入地图，在应用前台请求定位权限。获得位置后，以自己的位置居中。
- 蓝点标记自己的位置。定位更新只移动蓝点，不把用户正在拖动的地图强行拉回。
- 在地图与发现、收藏之间切换，保留之前的地图中心和缩放。视野保存在本次运行的内存中，
  不写入持久存储；重新启动应用或刷新网页，重新以当前定位和默认尺度初始化。
- 启动和点击“回到我的位置”时，横向视野约为每 100 布局单位 500 米；
  390 宽手机整屏横向约 1.95 公里。iOS 使用原生比例尺；Android 与网页短线固定宽度，
  公里/米数随缩放实时变化。触屏无加减按钮，层级由双指缩放自动过渡。
- 拒绝权限、定位超时或服务不可用时显示明确状态，保留参考地图，并提供重试按钮。
  此时不伪造用户蓝点，也不以参考城市位置查询“我的附近”。
- 本次使用前台定位；退到后台停止订阅，回到前台重新获取。未启用后台定位或系统推送。
- 原生端使用 `expo-location`；网页使用浏览器定位 API，需要 HTTPS 或 localhost。
  坐标只用于定位与附近查询，没有增加位置历史数据库。

## 什么算新活动

新活动按后端 `published_at` 判断，而不是按活动开始时间判断。首次运行检查最近 24 小时，
后续从上次成功查询的服务端时间继续。在地图前台每 60 秒检查一次；位置变化、切回地图、
应用回到前台时也会查询。15 公里半径以真实位置为中心，与拖动后的地图中心无关。

新增接口 `GET /api/v1/events/nearby-updates` 使用 PostGIS `ST_DWithin`（米）筛选：
已发布、尚未结束、未取消或延期、发布时间在查询窗口内的活动。
坐标、半径、时间范围和分页大小均经过校验。

参数：`latitude`、`longitude`，可选 `radius_km`（默认及上限 15）、`since`、`until`、
`offset`、`limit`（最多 500）。响应包含活动、`published_at`、分页信息和 `checked_at`。
后续页固定使用第一页的 `checked_at` 为上界；全部页成功后才推进本地检查时间。
请求中断或分页失败不会跳过尚未获取的新活动。

未读活动和已读键保存在本机。重启后恢复未读指引，重复查询同一发布版本不会再次提醒。
没有把演示数据当成真实新活动通知；附近接口不可用时会提示并稍后重试。

## 八方向动画

- 北、东北、东、东南、南、西南、西、西北八个方向，按活动相对当前视口的位置分配。
  初始视口以用户位置为中心；拖动后按新视口重新计算。
- 相邻方向用连续权重混合。每个方向内的活动按类别合并，动画图层数取决于方向和类别，
  不随活动总数逐个增加。
- 固定 32 段连续色带共享端点，使用高明度类别色和四边渐隐遮罩，宽约 17–21 像素。
  同方向类别错开相位循环混色，相邻方向连续过渡；边角面积由统一边框几何保证。
  活动与定位的距离只在输入变化时计算，动画帧复用缓存。
- 方向变化采用指数插值；附近活动的响应更快、短暂波动更明显，较远活动更轻。
  波动随后衰减回正常值，避免硬切颜色或突然跳动。
- 标记进入屏幕内部区域并停留 350 ms 后停止该次方向提示。内部区域排除了左右各 16%、
  顶部与底部控件附近的区域，不要求落在正中心。方向色彩约 1–2 秒渐隐。
  远景只显示收藏时，不会把尚未实际展示的新标记误记为已看过。
  原生地图拖动中尚未挂载的标记也不会提前停止提示。出现后保留 6 秒半透明光圈，
  黑色未读轮廓则一直保留到用户打开详情；光圈到期不算已读。
- 动画只更新独立的边缘覆盖层，每秒最多约 30 次，不反复刷新整张地图或所有标记。
  后台暂停；无有效提示且渐隐结束后停止循环。系统开启“减少动态效果”时，保留平滑透明度变化，
  停止波浪位移。覆盖层不拦截地图的点击和拖动。

## 参数位置

启动亮起 0.5 秒、调试时间与正式模式隔离见 [DEBUG_SETTINGS.md](DEBUG_SETTINGS.md)。

| 参数 | 位置 |
| --- | --- |
| 默认 500 米比例尺、15 公里半径、投影 | `mobile/src/map/geo.ts` |
| 八方向混合、中心区域、衰减和波浪形状 | `mobile/src/map/guidance.ts` |
| 350 ms 确认、动画刷新率、减少动态效果 | `mobile/src/map/EdgeGuidance.tsx` |
| 60 秒检查、前后台切换和持久化 | `mobile/src/map/useNearbyUpdates.ts` |
| 定位状态与生命周期 | `mobile/src/map/useDeviceLocation.ts` |
| 真实附近查询 | `backend/app/api/routes/events.py` |

无需数据库迁移，活动位置和发布时间字段原已存在。需同步部署新增后端接口和客户端，
并使用本次更新的 OpenAPI 与生成类型。原生应用加入了定位权限文案及 `expo-location`、
`react-native-svg` 依赖，独立安装包需重新构建。

## 验证

```powershell
# mobile/
npm run typecheck
npm run test:map
npm run test:guidance
npx expo export --platform web
npm run preview:map
# 在另一个终端
npm run smoke:demo
```

当前 200 条数据测试模式及启动方式见 [DEMO_DATA.md](DEMO_DATA.md)。
浏览器测试使用临时位置和活动，不读取用户真实位置。测试包含默认居中与比例尺、
多页附近活动、分页失败恢复、八方向多色波浪、从标记开始拖动、方向切换、复位、已读渐隐、重启去重、运行中新增活动、
减少动态效果和定位拒绝。截图在 `mobile/artifacts/guidance-*.png`。

后端运行 `uv run pytest`、`uv run ruff check app tests`。接口测试使用模拟会话检查
查询条件和响应契约；实际 PostGIS 执行、GPS 精度、原生地图标记及动画帧率仍需真机验证。
