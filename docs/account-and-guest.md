# 游客、个人资料与账号绑定

- 登录成功后，本机保存会话凭证；手机使用 SecureStore，网页使用同源 localStorage，不保存密码。启动、回到前台及运行期间每六小时调用 `POST /api/v1/auth/session` 核验当前账号并续期至 180 天后，正常使用不反复登录。连续 180 天未续期、账号停用或会话撤销后需重新登录。旧的有效会话可直接续期，无需数据库迁移。
- 退出会撤销当前设备会话并清除本机凭证，保留上次成功登录的邮箱，重新登录时自动填入邮箱、密码留空。其他设备的独立会话不受影响。临时网络失败保留凭证，允许重试或游客浏览。
- 设置 → 账号与安全 → 退出其他设备：输入当前账号密码确认后，`POST /api/v1/auth/logout-others` 撤销同账号的其他会话，保留当前会话。错误密码不退出当前账号，接口有尝试频率限制；其他会话在下次请求或续期时收到 401 并清除本地凭证。共享同一浏览器存储的标签页属于同一个会话。

- 首次登录页允许“暂不登录，随便看看”。游客可浏览发现、地图和活动详情；收藏、海报上传、纠错等账号操作引导到“我的”登录。
- “我的”展示头像、昵称与账号收藏。旧账号昵称为空时使用账号 ID 的短段生成展示名，不将邮箱当作公开昵称。收藏可在完整卡片和紧凑列表间切换，选择按账号保存在本机。
- 设置可选择内置头像、查看邮箱/身份/注册日期与退出登录。`PUT /api/v1/auth/me` 只允许修改头像，禁止提交角色等额外字段。数据库迁移 `20260917_0010` 为旧账号添加兼容默认值。
- 昵称修改在用户确认提示后通过 `POST /api/v1/auth/nickname-change` 提交；审核期间继续显示原昵称。重复提交会更新当前待审申请。管理员在“审批 → 昵称审核”填写审核说明并通过或拒绝；只有通过时才写入正式昵称。迁移 `20260918_0011` 保存申请和审核记录。
- `GET /api/v1/auth/bindings` 预留平台能力列表；微信目前返回 `available:false, bound:false`，界面显示暂未开放。没有虚假的绑定成功操作，也不接受客户端自行提交 OpenID 来绑定。
- 后续接入微信等平台时，应增加服务端验证授权回调、一次性 state 校验、平台身份与用户的唯一关联和解绑规则。快捷登录与绑定需共用经过验证的身份映射；不能仅凭邮箱或前端传来的平台 ID 合并账号。
- 调试开关仅向已登录管理员展示。应用重新启动及退出/登录失效时关闭调试，保留半径等配置但不自动继承权限。账号接口始终使用正式服务，不把账号令牌发送给临时数据服务。
- 调试期间保留管理员审批入口，显示暂停说明，不挂载审批编辑器；API 客户端同时拒绝调试时的 `/admin/` 请求。关闭调试后继续正式审批。

回归：后端 `tests/test_auth.py` 验证头像更新、昵称审批与角色隔离；`mobile/scripts/smoke-account.mjs` 使用临时账号验证游客、昵称待审与通过、收藏视图切换、微信预留入口、管理员调试提示及退出。
